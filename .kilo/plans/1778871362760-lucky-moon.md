# Plan: Corregir correo de soporte en bases de datos existentes

## Problema
El correo de soporte `alex.ziron7@gmail.com` no se muestra correctamente porque las bases de datos existentes (`restaurante.db` y `restaurante-demo.db`) tienen valores antiguos en la tabla `config` con `clave = 'email_soporte'`.

## Análisis
- El código fuente ya tiene el correo correcto en `database.js:175`
- El cliente `SoportePage.jsx:5` usa valores por defecto correctos y los sobrescribe con datos de `/api/config`
- Las bases de datos persistentes tienen valores obsoletos que prevalecen sobre los nuevos valores por defecto

## Solución
### Opción 1: Ejecutar script de corrección existente (Recomendado)
```bash
node scripts/fix-config-db.js
```
Este script actualiza directamente el correo en ambas bases de datos sin borrar datos.

### Opción 2: Borrar bases de datos (Si no hay datos importantes)
```bash
node scripts/clean-all-dbs.js
```
Esto recreará las bases de datos con los valores correctos, pero borrará todos los datos existentes.

## Verificación
1. Detener servidor (`Ctrl+C`)
2. Ejecutar script elegido
3. Iniciar servidor nuevamente (`node server.js`)
4. Verificar en la página de Soporte que muestra `alex.ziron7@gmail.com`
