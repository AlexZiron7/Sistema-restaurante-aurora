# 📜 Changelog - Sistema Restaurante

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.0.0] - 2026-05-14
### ✨ Añadido
- **Instalador Profesional:** Implementado con Inno Setup 6 para instalaciones fáciles en Windows.
- **Auto-Updater:** El sistema ahora puede detectar y descargar nuevas versiones desde GitHub.
- **Sistema de Migraciones:** Gestión automatizada de cambios en el esquema de la base de datos.
- **Firewall Auto-Config:** El instalador configura automáticamente las reglas para permitir conexión de tablets.
- **Documentación Completa:** Nueva suite de manuales para usuario y desarrollador.

### 🛠️ Mejoras
- Optimización del proceso de compilación con `pkg`.
- Mejor manejo de errores globales en el servidor.
- Sincronización mejorada de estados de mesa vía Sockets.
